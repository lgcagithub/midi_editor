## 钢琴键盘绘制思路

### 前置约定

- 本文的示例代码使用`cpp`语言来讲解，若要用于其他语言，请自行转换。
- 本文用到的坐标和尺寸皆未考虑画布的裁剪和缩放。
- 本文以绘制**横向**钢琴键盘来举例。在绘制*纵向*钢琴键盘时，请按需将横纵坐标、宽高等概念做适当的调整。
- 本文中的钢琴键盘逻辑位置为(`piano_keyboard_x`, `piano_keyboard_y`)，逻辑宽高为(`piano_keyboard_width`, `piano_keyboard_height`)。

---

### 关键要点

- 白键和黑键分别在不同层绘制。先绘制白键层，再绘制黑键层。
- 在白键层的一个八度内，按7等分来划分绘制，分别对应`C` `D` `E` `F` `G` `A` `B`。
- 在黑键层的一个八度内，按12等分来划分，分别对应`C` `C#` `D` `D#` `E` `F` `F#` `G` `G#` `A` `A#` `B`，但只有`C#` `D#` `F#` `G#` `A#`对应位置绘制黑键，其他位置不绘制任何内容。

---

### 详细思路

**黑白键的宽度**

在标准88键钢琴键盘中，音符范围为`A0`到`C8`。其中白键黑键的数量分别为：
``` cpp
// 0区2个白键`A0` `B0`，1区到7区每区7个白键（C D E F G A B），8区1个白键`C8`
int white_key_num = 2 + 7 * 7 + 1;  // 即52

// 0区1个黑键`A#`，1区到7区每区5个黑键（C# D# F# G# A#），8区没有黑键
int black_key_num = 1 + 5 * 7 + 0;  // 即36
```

那么每个白键的宽度为：
``` cpp
float white_key_width = piano_keyboard_width / white_key_num;
```
而黑键的宽度**不能**直接等于白键宽度乘以某个比例，因为那样做很容易会造成某些黑键位置算不对。黑键的宽度应该为：
``` cpp
// 一个八度有7个白键，所以白键宽度乘以7就得到一个八度的宽度。
// 而根据十二平均律，一个八度有12个半音。我认为黑键等于一个半音的宽度是比较合适的，所以除以12。
float black_key_width = white_key_width * 7 / 12;
```


**黑白键的起始偏移**

在白键层绘制白键时，首个白键`A0`相对于钢琴逻辑区域的横坐标是0。即：
``` cpp
float first_white_key_x = piano_keyboard_x;
```
但在黑键层绘制首个黑键`A#0`时却不能这么照搬。首个黑键相对于钢琴逻辑区域的横坐标应该为：
``` cpp
float first_black_key_x = white_key_width * 2 - black_key_width * 2;
```
我来解释上面这行代码是啥意思。首先0区没有完整八度，只有两个白键（`A0` `B0`）和一个黑键（`A#0`），两个白键的宽度就相当于0区的宽度了，所以`white_key_width * 2`算出的是0区的宽度。而黑键`A#0`在两个白键中间，各覆盖了两个白键的部分区域，白键`B0`去掉被`A#0`覆盖那部分剩下的宽度，可以认为也是一个黑键的宽度，所以黑键`A#0`的起始横坐标相当于从0区最右侧往回退两个黑键的宽度，即上述代码中的减去`black_key_width * 2`。

**每个黑白键的位置**

白键和黑键分别在不同层绘制。先绘制白键，再绘制黑键。在白键层我们有：
``` cpp
for (int i = 0; i < white_key_num; ++i)
{
    float key_x = first_white_key_x + white_key_width * i;

    //其他变量计算与绘制...
}
```
在黑键层我们有：
``` cpp
int total_key_num = 88;
float key_offset = first_black_key_x - black_key_width;
for (int i = 0; i < total_key_num; ++i)
{
    float key_x = key_offset + black_key_width * i;

    //其他变量计算...

    if (isBlackKey(indexToKeyNote(i)))
    {
        //绘制...
    }
}
```
我又来解释上面的代码是啥意思。白键层的计算逻辑已经很明显了，就不多说了。对于黑键层，上面有提到黑键`A#0`各占了两白键`A` `B`的一部分宽度，`B`剩下的那部分宽度刚好可以作为一个黑键的宽度，同理`A`也剩下了一部分宽度，但`A`剩下的这部分宽度是大于一个黑键宽度的，而多出的这点不足一个黑键的宽度，实际上是属于没有纳入88键钢琴键盘布局的`G#0`。所以黑键`A#0`前面实际上是存在一个不绘制的占位黑键宽度加上部分的黑键`G#0`宽度，为了刚好凑齐88个键方便理解代码，我们需要从`A#0`往回退一个虚拟黑键开始算，于是有了`float key_offset = first_black_key_x - black_key_width;`。我们遍历`A0`到`C8`这88个键，判断每一个是否黑键，是的话就绘制，否的话就默认不处理，这样就可以绘制出黑键层所有黑键了。上面的`isBlackKey()`和`indexToKeyNote()`都是假设的，你需要实现一个判断MIDI音符代码是否黑键的函数，还要实现根据键索引转换到MIDI音符代码的函数。
