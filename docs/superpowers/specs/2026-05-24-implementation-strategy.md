# 实现策略：垂直切片

## 决策

采用 3 条垂直切片推进，而非严格按 tasks.md 编号顺序。每条切片结束有可验证的里程碑。

## 第 1 片：骨架（~22 任务）

**里程碑：** 浏览器中看到 demo 音符 → 点键盘能试听 → 点播放听到声音、光标移动

**执行顺序：**
1. 项目脚手架 (1.1-1.6)
2. 视觉基础设施 (2.1-2.6)
3. 数据模型核心 (3.1, 3.3, 3.4, 3.5)
4. 状态管理核心 (4.1, 4.3)
5. 音频引擎核心 (6.1, 6.2, 6.6) — SoundSource + OscillatorBank + AudioContext 解锁
6. **钢琴键盘 (7.1-7.4, 7.6, 7.7)** — 先于 Piano Roll，确定 whiteKeySize → noteHeight
7. Piano Roll 渲染器 (8.1-8.3, 8.5, 8.6)
8. 播放 + 光标 (6.3, 6.7, 8.9)
9. 最小 UI (12.1, 12.4, 12.3)

**关键决策：键盘先于 Piano Roll。** 原因：
- noteHeight = whiteKeySize × 7/12，必须从键盘几何推导，不可写死
- 键盘 + OscillatorBank 连接后即可点击试听，在 Canvas 渲染之前就有交互反馈

## 第 2 片：核心（~30 任务）

**里程碑：** 加载/保存 .mid 文件、画笔/指针/橡皮编辑音符

- 数据模型补充 (3.2, 3.6)
- MIDI 文件读写全部 (5.1-5.11)
- 状态管理补充 (4.2, 4.4)
- 音频引擎补充 (6.4, 6.5, 6.7, 6.8)
- 渲染器补充 (8.4, 8.7, 8.8, 8.10)
- 音符交互全部 (9.1-9.12)
- UI 补充 (12.2, 12.8)

## 第 3 片：完善（~21 任务）

**里程碑：** 完整体验 — 键盘点击试听、撤销重做、吸附网格、横纵向切换

- 钢琴键盘补充 (7.5, 7.8)
- 渲染器补充 (8.11)
- 吸附网格全部 (10.1-10.5)
- 撤销/重做全部 (11.1-11.9)
- UI 补充 (12.5-12.7)
- 集成收尾全部 (13.1-13.6)
